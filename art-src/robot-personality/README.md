# Eeri robot / small-machine personality pack

Personality is **secondary motion and reaction**, never a new enemy mechanic. The existing hopper, roller, bucket and skitter behaviours remain the gameplay truth.

## Shared character rules

- They look busy, sleepy, curious or startled — never angry.
- Personality yields immediately to telegraph/wind/lunge/hop gameplay states.
- A stomp reads as a comic machine mishap: squash, loose-part pop, then stillness; no pain language.
- Nearby machines can earn a glance or tiny body turn only while the robot is in a safe idle/patrol part of its cycle.
- No personality reaction changes collision, speed, detection radius or telegraph duration.

## Individual reads

- **Hopper:** impatient metronome. Tiny pre-hop collar compression; after landing it does one settling shimmy.
- **Roller:** diligent and oblivious. Drum keeps rolling; at an edge it pauses a beat as if checking its work, then turns.
- **Bucket:** genuinely sleepy. The existing head-lift telegraph is the character beat; asleep it occasionally slumps a few degrees deeper.
- **Skitter:** curious. Patrol eye scans the set; notice locks the eye on Eeri before the existing wind-up begins.

The lab is intentionally schematic: it is for approving rhythm before any code is ported into `robots.js`.
