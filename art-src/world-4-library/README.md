# World 4 library — Evening warehouse / loading dock

Optional source art for **World 4: the evening construction site under lights**, specifically warehouse / loading-dock scenery.

## Rules
- Single sheet per asset or small approved group (max 4 items per sheet for the newer grouped sets).
- Crafted handmade industrial style only: painted card, fibreboard, cardboard, felt, tape, brads, visible material texture.
- Keep gameplay silhouette readable; some larger hero pieces are included but may need cropping for the flatter camera.
- No clouds baked into assets.

These are source-only optional pieces and should not be auto-promoted into production assets or manifests.
