# EERI approved machine concepts

Owner-approved source concept sheets from the machine visual-development pipeline.

## Approved

- `machines/machine-roster-dark-eyes-approved.png` — **primary face direction**. Small dark Eeri-like eyes; explicitly approved and later said to keep.
- `machines/machine-roster-toko-face-approved.png` — **approved alternate** using the exact Toko face grammar: arched smiling eyes plus the U-shaped mouth.

## Use

These are **concept/style references**, not production GLBs and not automatic manifest entries. For Meshy, rebuild/extract each promoted machine as a single subject on a plain neutral background, full object in frame, no cast shadow, using a clean 3/4 plus front/side/back views where useful.

Vehicles/machines use Meshy image or multi-image to 3D and then rigid-node slicing. Do **not** humanoid-rig vehicles. The current canon ride-machine set remains excavator, crane, pipe-layer, cherry-picker and floodlight rig; other machines visible in exploration sheets are vocabulary only until design promotes them.

Superseded/rejected face experiments are intentionally excluded.
