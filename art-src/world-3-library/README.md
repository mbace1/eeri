# World 3 library — Forest clearing and digs

Optional source art for **World 3: forest clearing and digs**. This world is not “World 1 plus trees”: the material language shifts toward fibrous, earthy and organic craft materials while keeping the same handmade diorama grammar.

## Style lock

- Crafted World first: layered kraft/card earth, visible corrugation, felt/moss, cut paper leaves, cardboard bark, tape, brads and simple timber construction.
- Construction meets nature: roots, stumps, cut banks, timber braces, retaining work, survey ribbon and log/tunnel forms.
- Keep the game plane flat and readable; depth comes from layering and crop, not from putting props on a 3D floor plane.
- Organic shapes should still visibly look *made*: hand-cut edges, layered card strata, corrugated cores, simple fasteners.
- No baked clouds. No realistic forest painting. No photo bark/soil textures.

## Use

Read `CATALOG.md` for current pieces. Agents may crop, layer, recolour and recombine them into level-specific compositions. Promotion into `eeri/assets/**` is a separate deliberate art-lane action.
