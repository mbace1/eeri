# World 3 library — Forest clearing and digs

Optional source art for **World 3: forest clearing and digs**.

## Rules
- Single sheet per asset or small approved group (max 4 items per sheet for the newer grouped sets).
- Crafted handmade style only: layered kraft/card earth, visible corrugation, felt moss, cardboard bark, tape, brads, simple timber construction.
- Flat gameplay plane readability first. Some taller/deeper pieces are still included as optional source art but may need cropping for the flatter in-game camera.
- No baked clouds. No realistic forest painting.

These are source-only optional pieces and should not be auto-promoted into production assets or manifests.
