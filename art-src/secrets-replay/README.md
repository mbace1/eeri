# Eeri secrets & replay pack

Replay should create **curiosity**, not completion anxiety. A level may show what Eeri found and that something remains, but it should not expose a secret's exact location or imply the level was failed.

## End-of-level card

The card is brief and non-blocking:

- Bolts: `73 / 100` — the ordinary completion figure.
- Golden bolts: three physical slots, filled or empty (`● ● ○`), never a red X.
- Blueprint/world collectible: shown only once its world has introduced that collectible language.
- Primary action remains **Next level**. Replay is secondary.

## Replay rules

- Any unlocked level is replayable from Level Select using the existing `EERI W-L` labels.
- Replaying never relocks later levels.
- Previously found hidden collectibles remain visibly found; the level may still place them according to runtime rules, but the shell never pretends they are unknown again.
- Do not add star ratings, grades, medals or timers.
- A completed `100/100 · 3/3` level gets a small crafted stamp, not a new progression gate.

## Secret hint ladder

First play: no explicit hint. After a level has been completed once with missing golden bolts, Level Select may use a soft phrase/icon such as **"something left here"**. It never points to a room coordinate.
