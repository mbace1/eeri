# EERI — Worlds 3–4 Art Pass 2

Status: **visual-only playtest dressing**. No collision or level-layout changes.

## Goal

Make the six World 3/4 greyboxes read as six authored places, and visually reinforce the mechanic each room is testing. This pass deliberately avoids adding decorative clutter just because an asset exists.

## World 3 — Forest clearing / root work

### 3-1 — The Cut Bank
- hollow-tree mass establishes the world immediately
- exposed root pockets reinforce the springy/tarp beats
- felled timber frames the elevated route
- stump/clearing mass opens around the machine section

### 3-2 — The Timber Lift
- timber work frames sit behind both real hoists
- placed log beams make the vertical route read as forestry work
- final chasm is visually framed as a felled-log job rather than a generic bridge

### 3-3 — Root Works
- denser roots and stump-clearing language than 3-1/3-2
- timber frame supports the final vertical beat
- machine/wall finale sits inside an obvious root-clearing zone so it does not visually fall back to World 1

## World 4 — Evening warehouse / loading dock

The approved direction is the owner-supplied grey loading dock, blue warehouse and blue/orange gantry crane: cool blue/grey card, warm amber work lights, yellow/orange safety hardware and hazard stripes.

### 4-1 — The Night Shift
- grey loading-bay/service-wall composition
- each conveyor section gets a loading-lane slab behind it
- barriers, cable reel, worklight and cargo close the scene without obscuring gameplay

### 4-2 — The Lit Scaffold
- blue three-bay warehouse is the dominant architecture
- both hoists visually service raised decks, tying the platforming to the building
- loading slab, worklights and cargo reinforce vertical service-yard work

### 4-3 — Last Lights
- warehouse is intentionally darkened/quieted
- a large gantry owns the final screen and machine zone
- early dock slabs create a visual runway toward the gantry rather than another uniform warehouse room

## Asset gaps — only the useful ones

The Library already contains enough general forest and warehouse vocabulary. **Do not make another broad prop sheet just for this pass.**

Highest-value additions:

1. **World 3 timber hoist / forestry lift frame** — one clean transparent hero piece that can replace the procedural timber frames in 3-2.
2. **World 3 uprooted root / root-wall job, preferably before + cleared states** — gives 3-3 a unique machine payoff visual rather than a construction-wall proxy.
3. **Alpha-prepped versions of the three approved World 4 hero pieces** — grey loading dock, blue warehouse, gantry crane. Their source composition is already approved; this is cleanup/integration, not another concept round.
4. **World 4 modular service deck** — yellow railing + ladder + metal/card platform, clean transparent piece for 4-2.
5. **World 4 floodlight-rig hero machine / aiming states** — not required for current greybox testing, but this is the important future asset if 4-3 is going to end with World 4's own interaction rather than the temporary crane/wall gameplay.

Lower priority: more crates, cones, barrels, signs, foliage, mushrooms, rocks or generic warehouse clutter. The existing Library already covers those categories well enough for testing.
